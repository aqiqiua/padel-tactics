# 🎾 Padel Tactics — тактическая доска (Telegram Mini App)

Интерактивная доска для разбора тактики в паделе прямо внутри Telegram.
Перетаскивай игроков и мяч, рисуй перемещения, траектории и зоны, делись схемой.

## Возможности

- **Корт падела** сверху (20×10 м) с сеткой, линиями подачи и центральными линиями
- **4 игрока** (2 команды) и **мяч** — перетаскиваются пальцем
- **Инструменты рисования:** кисть (от руки), стрелка, линия, ластик
- **6 цветов** и 3 толщины линии
- **Отмена**, очистка рисунка, сброс позиций
- **Экспорт** схемы в картинку (шэринг в чат или сохранение)
- Тёмная/светлая тема подхватывается из Telegram, тактильная отдача (haptics)

## Файлы

```
index.html   — разметка и подключение Telegram SDK
style.css    — оформление (адаптивно + темы Telegram)
app.js       — вся логика: корт, перетаскивание, рисование, экспорт
```

Никакой сборки не нужно — это статические файлы.

## Локальный запуск

```bash
cd "Padel Tactics"
python3 -m http.server 8770
# открыть http://127.0.0.1:8770
```

## Как выложить в интернет (нужен HTTPS)

Telegram Mini App открывается только по **https**. Любой из вариантов подойдёт — это просто статические файлы:

### Вариант 1. GitHub Pages (бесплатно, навсегда)
1. Создай репозиторий на GitHub, залей эти файлы.
2. Settings → Pages → Source: ветка `main`, папка `/root`.
3. Через минуту получишь адрес вида `https://<user>.github.io/<repo>/`.

### Вариант 2. Netlify Drop (без аккаунта, за 30 секунд)
1. Открой https://app.netlify.com/drop
2. Перетащи туда папку `Padel Tactics`.
3. Получишь адрес вида `https://<random>.netlify.app`.

### Вариант 3. Cloudflare Pages / Vercel
Тоже подходят — залей папку как статический сайт.

### Вариант 4. Быстрый туннель для теста (адрес временный)
`cloudflared tunnel --url http://localhost:8770` → выдаст `https://…trycloudflare.com`.

## Подключение к боту (через @BotFather)

Когда есть публичный HTTPS-адрес:

1. Открой **@BotFather** → `/mybots` → выбери своего бота.
2. **Bot Settings → Menu Button → Configure menu button**.
3. Вставь URL приложения и задай название кнопки (например «Тактика»).
4. Готово — кнопка меню в чате с ботом откроет Mini App.

Альтернативно можно создать Mini App через `/newapp` и открывать по прямой
`t.me/<bot>/<appname>`-ссылке.

## ⚠️ Безопасность токена

Токен бота (`123456:AA...`) — это пароль от бота. Не публикуй его в коде,
репозитории или чатах. Если он где-то засветился — перевыпусти:
**@BotFather → /revoke**. Приложению токен **не нужен** — оно работает целиком
на стороне клиента.
